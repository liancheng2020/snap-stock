# 设计与迭代

## v1.0：技术面解读闭环

目标用户：不会阅读技术指标、希望理解近期历史走势的个人用户。

请求流：代码校验 → 行情适配 → 日期/复权/数据质量检查 → 指标 → 交叉事件 → 规则解释 → 图表定位。服务器不接受任意目标 URL，避免行情接口成为开放代理。

第一版选择 Node.js 单服务、原生模块和 SVG：无任务队列、无数据库、无模型服务，保持安装简单。单次请求有20秒源请求超时，最多4个并发任务；缓存最多100证券、5分钟。下载 JSON 用于保存分析快照，不在服务端保存个人历史。

信号与图表采用同一批数据。金叉前日 DIF≤DEA、当日 DIF>DEA，死叉相反。中期状态依据价格相对MA60的位置与MA60较5日前的方向。量能只作描述，不给出独立的买卖推荐。

数据限制：当前用非官方 Yahoo 接口验证三个市场，不能承诺全部证券覆盖。排除交易所当地今天是一种保守策略，不具备交易所完整日历及提前收盘识别；应在下一阶段用授权数据和交易日历替代。公司名称缺失时显示代码，不编造名称。

## 后续

1. 交易日历、明确可用的当日收盘确认、证券搜索和数据源适配接口。
2. 可选 DeepSeek 解释器：只接受已计算事实，输出引用的事实 ID；验证失败回退规则文本。没有真实评估前不宣传 AI 准确率。
3. RSI、周线、条件观察清单与本地历史快照；先验证数学定义和边界。
4. 更丰富的无障碍图表与交互测试。无自动交易、荐股评级或未经验证的胜率。
