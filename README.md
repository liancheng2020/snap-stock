# Snap Stock

> 看懂走势，不止看见指标。

输入 A 股、美股或港股代码，查看近期日线、均线、MACD 与成交量，并获得有数值依据的通俗解读。**不是荐股或收益预测工具。**

![真实港股日线与技术信号界面](docs/screenshot.png)

截图为开发验收时的历史行情结果，不是当前行情或投资建议。

## v1.0

- 真实行情：沪深 A 股、美股、港股代码适配；展示公司、交易所、币种、时区与截至日期。
- 可视化：K 线、MA20/MA60、成交量、MACD；1/3/6 个月展示范围。
- 交叉事件：识别金叉/死叉发生日，点击信号定位图表，查看前后 DIF/DEA 数值。
- 规则解读：趋势、动能、分歧与限制；区分“新发生交叉”和“仍处于交叉后的状态”。
- 数据透明：两年历史计算、5 分钟缓存、超时与并发限制，失败明确提示，不返回模拟行情。
- 导出包含源信息、参数、指标与信号的 JSON 快照。

指标及信号由程序计算，默认模型提供方为 **DeepSeek**，只基于这些事实生成通俗解释。模型文字与规则结论分开展示，可展开查看引用事实；无 Key、超时或格式校验失败时明确回退规则解读。不包含自动交易或多 Agent，引用校验不代表语义绝对正确。

在根目录 `.env` 中配置 `DEEPSEEK_API_KEY`，可选 `DEEPSEEK_BASE_URL=https://api.deepseek.com`、`DEEPSEEK_MODEL=deepseek-chat`，保存后重启。模型只接收指标事实，不接收密钥以外的本地配置；不使用模型补造缺失行情。

## 启动

Node.js 22+，Windows / macOS / Linux 通用：

```sh
npm ci
npm start
```

打开 http://localhost:3100 。规则模式不需要模型 Key 或数据库，DeepSeek 解读需配置 Key。

遇到行情 403：这是数据源拒绝请求，不是模型错误。请配置可访问 Yahoo 的 HTTP 代理 `DATA_PROXY_URL`；本机浏览器的代理插件不会自动作用于 Node。接入模型不能解决行情访问限制。

无法访问行情源时，将 `.env.example` 复制为 `.env`，设置 `DATA_PROXY_URL=http://127.0.0.1:你的代理端口`。可通过 `PORT` 修改端口。修改后重启服务；不要提交本机配置。

示例代码：A 股 `600519`、美股 `AAPL`、港股 `00700`。请核对返回的公司名和交易所，暂不支持名称搜索、北交所和全部特殊证券。

## 口径与边界

- 日线：**保守排除交易所当地今天的全部数据**，即使已收盘也在次日纳入；不是实时或当日收盘即时服务。
- OHLC 使用源 `adjclose/close` 比例调整，成交量保持源值；不将该口径冒称国内软件完全一致的前复权。
- MA20/60；MACD 12/26/9，EMA 用首 N 项 SMA 初始化，柱状图为 `2 × (DIF − DEA)`。
- 获取近两年历史，至少 120 根有效日线；图表范围不改变指标计算。休市不补零，源缺失或非法日线拒绝分析。
- 数据：Yahoo Finance 非官方接口，无稳定性承诺，可能限流或延迟。仅作个人学习用途，商业分发应另行核对许可或更换授权数据源。[Yahoo 数据说明](https://help.yahoo.com/kb/finance/SLN2310.html)。
- 涨绿跌红；成交量比值是当日量 / 前20个交易日均量，不是盘中量比。指标相互相关，金叉不等于买入或必然上涨。
- 服务默认只监听本机，尚无鉴权、多用户配额和持久化任务；不要直接开放公网。

## 开发

```sh
npm run dev
npm test
```

浏览器验收：服务启动后执行 `npx playwright install chromium`、`node scripts/verify-ui.mjs`。这会访问三个市场的真实行情，依赖网络；单元测试不联网。

结构：`lib/market.js` 行情适配与校验；`lib/indicators.js` 指标与规则；`server.js` HTTP；`public/` 界面与 SVG 图表。无需前端构建。
